# 10 · 界面降噪（大厅 + 做题页）

## 本文件的作用
两屏（Bug 闯关大厅 + 做题页 workspace）都犯同一个病——**主角并列太多、没有焦点**。本文件用一条统一原则把两屏一起重做。
**本轮只出设计，不写代码。** 前置：接着做（`586d35b`）+ 轻量登录（`a2e4b0a`）均已本地 commit（未 push）；当前大厅 v1 视觉改动（仅未提交的 `Arena.vue`）验收不好，按本计划推翻重做。

---

## 统一原则
> **一屏一主角。** 每屏只允许一个「现在最该做的事」是视觉焦点，其余一律降级、收起或收进入口。

- 大厅的主角 = **开一道新题**
- 做题页的主角 = **左代码 / 右知返**

---

## 信息架构（三页分工，B+ 方向）

ACP **不是题库系统，是学习系统**。三页各司其职，不再把所有入口堆在大厅：

| 页面 | 回答的问题 | 承担 |
|---|---|---|
| **大厅 Arena** | 我现在要不要开始？ | 智能开一题（主角）+ 接着做档案 + 灵犀一句 + 一个安静入口「查看推荐与题库」 |
| **能力画像 Profile** | 我现在什么状态、该练什么？ | 能力雷达 / 弱点 + 智能推荐 + 浏览全部题目（**推荐/浏览搬到这里**） |
| **做题页 Workspace** | 我怎么做下去？ | 左代码 / 右知返 |

- **大厅不再承担"所有题目入口"**，只承担"马上开始"。
- **能力画像从"看报告"升级为"从我的状态出发决定练什么"的选题中枢**——智能推荐放它旁边才自然（推荐本就是从画像算出来的，"你哪弱 → 推这道"，理由可见）。
- 一句话三层：**我现在开始吗？→ 大厅　我该练什么？→ 能力画像　我怎么做下去？→ 知返。**

**执行节奏（B+：按 A 定方向、按 B 拆步）**：
- **本轮**只做大厅极简化 + 一个**安静入口指向能力画像**；推荐/浏览**先不真正搬**，大厅也不再铺它们的列表。
- **下一轮**单独把智能推荐 / 浏览全部**真正搬进能力画像**（动 `Profile.vue`）。本轮**不动 Profile 实际功能**。
- 再下一轮才做做题页 workspace。**不要一轮同时改大厅 / Profile / workspace 三块。**

---

## Part 1 · 大厅（极简版 = 快速开始页）

大厅 = **快速开始页**。本轮极简化，只保留：主角 + 灵犀一句 + 接着做档案 + 一个安静入口。

### 主角 = 智能开一题
- 中央一个大按钮「**智能开一题**」（不指定题，后端按画像/随机挑）——大厅唯一视觉焦点。
- 顶部说明收成一句副标题。
- 设计判断：学生打开 app 多半想做点新的，而不是回去啃没做完的——所以新题立为主角。

### 灵犀一句招呼
- 主角上方一句「读过你」的安静招呼，详见 [[acp-lingxi-presence]] / `docs/design/11`。至多一句、命中才出现、不追问不诊断、给选择留出口。
- 它给大厅补"温度"，也避免极简后显得空。

### 接着做 → 档案入口（文字按钮，不铺卡片）
- 「Bug 闯关训练场」标题旁放一个**稳定的文字按钮「接着做」**（**不用图标库、不用可能渲染失败的 SVG**——上一版图标渲染成空白方块，弃用）。带 `title` + `aria-label="接着做"`，**不带数字**。
- 点它 → 弹出**档案面板**，未完成关卡在面板里列出，可「继续 / 放弃」。
- **复用现有后端与函数**：`/active-sessions`、`resume()`、`abandon()` 全不动——只是把展示从「大厅铺卡片」挪进「文字按钮点开的面板」。**不改业务逻辑。**
- **移除**：当前大厅里的「接着做」内联区（resume 卡片 + 展开/收起，属 commit `586d35b` 的展示层）。后端不动，仅前端展示改由档案面板承接。

### 推荐 / 浏览 → 不在大厅，留一个安静入口
- 大厅**不再铺**智能推荐列表、也不铺题库分组。
- 取而代之：一行很安静的入口「**查看推荐与题库**」→ 跳能力画像页。
- **本轮只做这个入口**；把推荐 / 浏览**真正搬进能力画像**是**下一轮**（动 `Profile.vue`）。本轮 Profile 实际功能不动——入口先指过去，落地下一轮补。

### 长期 → B（档案变"成长记录"）
- 这个档案面板就是将来长成「**记录 / 推测你为什么停下** + abandoned 会话 + 成长档案」的地方。
- **现在做成独立面板**，B 阶段只是往里加内容，**不用重写**。与 [[acp-resume-feature]] 的 abandoned（不删历史/事件流）、成长轨迹 Timeline 是一条线。

### 已知取舍（用户已拍板）
- 档案入口用**文字按钮**而非图标，稳定优先；**不带数字**。
- 可选未来项（不在本轮）：有未完成时入口旁加一个**极淡小圆点（非数字）**作提示——若真出现"学生找不到未完成题"再议。

## Part 2 · 做题页 workspace（左代码 / 右知返）

砍掉中间「我的思考过程」那层——它已从辅助长成主角，把知返挤到墙角（现右栏是一个 `.thinking-panel` 塞了 阶段语境→四步线→对话→输入框，聊天被压在最底）。

### 两个代码核对出的硬约束（务必处理，别当纯 CSS）
1. **四步线里嵌着两个真交互**：观察卡（勾选 + 猜测 `submitObservation`/`skipObservation`）在第 1、2 步；总结输入（`submitSummary`）在第 4 步。→ 收起四步线时，**把这两个交互抽成内联小卡**（观察卡在运行后出现、总结卡在 ⑥内化出现）。**函数不动，只挪 DOM**。
2. **stage-bar 里有「退出关卡」按钮**（还有"提示级别"、阶段说明）。→ 删 stage-bar 时，**把「退出关卡」挪到右侧知返标题旁**，别丢。提示级别/阶段说明可降级或舍。

### 落地步骤
1. 删顶部 `stage-bar`；阶段 chip（`现在 · 发现`）+「退出关卡」挪到右栏知返标题旁。
2. 右栏面板标题「我的思考过程」→「**知返**」。
3. 四步线收成**一行细进度**（观察 → 猜测 → 验证 → 总结，纯展示）；观察卡 / 总结输入抽成内联小卡，按时机出现，不长期占屏。
4. **聊天框上移**，成为右栏最大区域（默认主体）。
5. 左侧「卡住时的小工具」整块收成一个轻入口「**看不懂代码？**」；「逐行讲解」也并进这个入口。左侧主按钮只剩「运行」。
6. 终端默认折叠成一条状态条（`consoleOpen` 默认 false，状态行常显：如「运行报错：IndexError」），点开才看完整 traceback。

### 最终视觉
```text
左：我正在看的代码          右：知返正在陪我想
代码框撑满 + 运行            知返标题 [现在·发现] [退出]
终端一条状态条              一行细进度（观察→猜测→验证→总结）
「看不懂代码？」轻入口       聊天为主体 + 输入框
```

- 不加"先选模式"的门、不加数字角标。
