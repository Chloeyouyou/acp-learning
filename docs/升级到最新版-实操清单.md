> ① 已装免密公钥,ssh/scp 不用密码;② 升级时用本地 `backend/acp.db`(已清理、含真实学号 `stu_n6ooz8`)覆盖 VPS 库,顺带绕过老库「无 students 表 → 登录 500」的坑。

## 窗口 ①(SSH,进 VPS 后一直用它)

```bash
# 0. 连上(免密,直接进)
ssh root@72.11.133.118

# 1. 抄下 AI 的 key —— 复制打印出来的 sk-... 存好,第 6 步要填
docker exec acp printenv DEEPSEEK_API_KEY

# 2. 拉最新代码(弹账号密码=令牌过期,停下)
cd /root/acp-learning
git pull

# 3. 预拉沙箱镜像
docker pull python:3.12-slim

# 4. 重新打包(几分钟,末尾出现 naming to ... acp-learning 即成功)
docker build -t acp-learning .

# 5. 备份现有库 + 删旧容器 + 清掉旧库文件(为 scp 覆盖腾位)
cp /root/acp-data/acp.db /root/acp-backup-$(date +%F).db
docker rm -f acp
rm -f /root/acp-data/acp.db*
```

**做完第 5 步先别动窗口①,切到窗口②。**

传完(免密,秒传)回到窗口①继续。

## 窗口 ①(接着敲)

```bash

## 两点说明

- 第 5 步先删库文件、再 scp 覆盖,是为了顺带解决老库「无 students 表 → 登录 500」的坑——直接换成本地已含 `stu_n6ooz8` 的新结构库,启动就是好的,不走「先跑起来发现 500 再回头修」的绕路。
- 覆盖会替换掉 VPS 上当前的库,但第 5 步已先 `cp` 成 `/root/acp-backup-日期.db` 兜底,真有问题能回滚。若不确定 VPS 上有没有别人的新数据要保留,先只做到第 5 步备份、把那份 backup 下载下来看一眼再决定是否覆盖。

## 回滚(万一新版启动后不对)

```

## 踩过的坑(排查记录)

**点「运行」报 `运行失败:请求失败 (500)`,但登录/其它都正常**
根因链:`ACP_SANDBOX="docker"` 强制 docker 沙箱、不静默降级 → 跑代码时容器内执行 `docker run` →
容器里**没有 `docker` 客户端命令**(`exec: "docker": executable file not found`)→ 后端抛异常 → 500。

为什么容器里没 docker(2026-07 实测):base 镜像 `python:3.12-slim` 已升到 **Debian 13 (trixie)**,
trixie 把 `docker.io` 拆成了 `docker.io`(仅 daemon)+ **`docker-cli`**(客户端命令)。
Dockerfile 里装 `docker.io` 只得到 dockerd、没有 `docker` 命令 → 沙箱调不起来。
**修复**:Dockerfile 改装 `docker-cli`(本仓库已改;只需客户端,daemon 用宿主的)。改完 `docker build` 重打、`docker rm -f acp` 再按上面第 6 步重起。

自查命令:
```bash
docker exec acp docker run --rm python:3.12-slim python -c "print('sandbox ok')"  # 打印 sandbox ok = 通
docker run --rm acp-learning sh -lc 'docker --version'                            # 镜像里有没有 docker 客户端
```

**先不折腾、只想自己单测能用**:重起时去掉 `-e ACP_SANDBOX="docker"` 和 `-v /var/run/docker.sock:...`,
改成 `-e ACP_SANDBOX="subprocess"`。不隔离,仅可信单机用。

**两个手滑点**
- `printenv` 后面跟的是**变量名** `DEEPSEEK_API_KEY`,不是 key 的值;写错会让 `$KEY` 变空 → 容器没 key,导师对话挂。
- 命令没在 VPS 上跑而在本机 PowerShell 跑:提示符 `root@racknerd...#`=在 VPS(有效);`PS C:\...>`=在本机(docker 命令都会失败,`\` 也不是 PowerShell 的换行符)。SSH 掉线(`Connection reset`)后要重新 `ssh` 连上再敲。
