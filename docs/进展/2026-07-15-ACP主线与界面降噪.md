# ACP 主线归拢与界面降噪进展（2026-07-15）

## 结果

本轮没有新增产品模块，而是把现有能力重新分层为一条主线：

```text
开始练习
→ 当前只做一个调试任务
→ 学生亲自运行、修改、解释
→ 回看真实动作与关键转折
→ 过程证据沉淀为成长、画像与教师洞察
```

前层负责降低选择和理解成本，后层负责把已有证据组织得更完整。

## 前层减法

### 入口

- 一级导航从 6 项缩到 `开始练习 / 学习地图 / 我的成长` 3 项。
- `AI 共脑调试 / 提问训练 / 能力画像` 保留在“更多”菜单，功能未删除、原路由不变。
- 身份页只保留一句价值说明：“陪你想通，不替你写完”，并缩短找回进度说明。
- 导航身份只显示姓名；学号仍保存在身份状态中，不再占据首屏空间。

### 训练大厅

- 首屏从“Bug 闯关训练场”改成用户任务“今天，自己想通一个问题”。
- 有未完成会话时，唯一主按钮为“继续上次”；没有时为“开始一次调试”。
- 新题、自由选关和未完成会话管理降为安静的次级动作。
- 自由选题统一进入“学习地图”，不再从大厅重复跳转画像/题库。

### 练习过程

- 全屏练习页移除第二套重复导航，只显示品牌、当前阶段、学生和退出。
- 保留六阶段方向感，但“观察—猜测—验证—总结”默认只显示当前需要的一步。
- 用户可主动展开“完整思考记录”，原有表单、观察卡和总结入口均保留。
- 逐行讲解、符号和概念继续放在“需要时再打开”的帮助层。
- 完成后先提供“回看我是怎么想通的”，再提供变式或下一次练习。

## 后层加法与归拢

### 我的成长

- 成长轨迹升级为主成长入口，明确展示：
  `真实动作 → 关键转折 → 内化经验`。
- 复习定义为“下一步”，思维默认值定义为“长期发现”，逐题内容统一归到“过程记录”。
- 能力画像成为从成长证据继续下钻的次级入口。

### 回放、画像与教师

- 回放先回答“这次我是怎么想通的”，再呈现完整时间线。
- 学生首先看到“亲自运行/亲自提交”的人话证据；`risk_level`、`call_id` 等技术信息收进“查看技术凭据”。
- 能力画像增加“结论来自真实过程证据”的说明，并可回到“我的成长”。
- 教师端明确下钻顺序：班级共性 → 需要关注的学生 → 单局真实过程。
