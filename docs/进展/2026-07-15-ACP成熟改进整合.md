# ACP 成熟改进整合进展（2026-07-15）

## 本轮结论

已把 ACP 现有的过程事实、知返固定教学策略、Resource Gateway 动作治理和教师视角连成一条可见、可回放、可衡量的链路。六阶段状态机、导师不泄题红线和四张事件事实表均未改动。

## 1. 过程回放 2.0

`services/process.py` 在读取回放时纯派生四类标记：

- `first_failure`：第一次真实失败，让问题从猜测变为事实；
- `targeted_change`：失败后第一次修改命中关键行；
- `error_changed`：错误族发生变化，说明执行路径被改变；
- `breakthrough`：失败后第一次通过，形成观察—修改—验证闭环。

回放数据新增：

```json
{
  "turning_points": [{"version": 3, "type": "breakthrough", "title": "这里出现了关键突破"}],
  "teaching_metrics": {"confusion_turns": 1, "recovery_rate": 1.0},
  "steps": [{
    "kind": "code",
    "error_family": "IndexError",
    "annotations": [],
    "action_context": {"purpose": "verify_hypothesis", "risk_level": 1, "call_id": "call_..."}
  }]
}
```

`Replay.vue` 已展示转折摘要、每一步转折解释、动作目的/风险/执行状态/证据编号；当导师因“听不懂”换路时，会显示“改用极小例子/执行链”等说明。

## 2. 导师教学策略留痕与指标

### 数据结构

`session_messages` 新增 `meta JSON NOT NULL DEFAULT {}`，迁移：

- `backend/alembic/versions/e4a9c7d21f30_add_session_message_meta.py`

导师每轮消息一次性写入：

```json
{
  "teaching_strategy": {
    "core_goal": "只找出异常沿执行路线经过的可疑位置",
    "explanation_route": "micro_example",
    "confusion_detected": true,
    "route_changed": true,
    "knowledge_gap": "下标/索引",
    "code_explanation_order": []
  },
  "stage_before": "②定位",
  "stage_after": "②定位",
  "student_progressed": false,
  "support_mode": true,
  "hint_level": "L2"
}
```

### 触发条件

- 学生明确说“听不懂/太抽象/看不懂”等，或连续无进展达到阈值：`confusion_detected=true`，切换解释路线；
- 命中下标、函数调用、循环边界、空值等前置断层：记录 `knowledge_gap`；
- 下一至两轮出现学生进展或阶段前进：计为“两轮内恢复”。

`process.teaching_metrics` 可从 append-only 消息重放出导师轮数、困惑轮数、换路次数、知识断层次数、两轮恢复数/恢复率和路线分布；旧会话没有 meta 时返回全零，不伪造历史。

## 3. 教师端加深

新增纯派生能力：

- 班级共性卡点：按当前 active 会话的 `pattern_id + stage` 聚合去重学生数；
- 学生钻取：进度、当前卡点、最近十局、每局及累计教学指标；
- 教师回放：复用同一个 `build_replay`，不另造教师数据副本。

新增接口：

- `GET /api/teacher/students/{student_id}`
- `GET /api/teacher/sessions/{session_id}/replay`

教师页现在可以从班级总览点击学生，查看困惑换路和恢复率，再进入具体会话回放。

## 4. 生产安全硬门槛

显式设置 `ACP_ENV=production` 后，应用启动前必须同时满足：

1. `ACP_SANDBOX=docker`；
2. Docker CLI 与 daemon 真实可用；
3. `ACP_ADMIN_TOKEN`、`ACP_AUTH_SECRET`、`DEEPSEEK_API_KEY` 均已配置。

任一不满足即抛出 `production_security_gate` 并拒绝启动，不再静默降级到 subprocess。开发环境保持原来的本地 fallback。

教师/管理员接口优先使用：

```text
Authorization: Bearer <ACP_ADMIN_TOKEN>
```

教师前端只把口令保存在 `sessionStorage`，不再把口令放进 URL；query token 只作为旧 QA 调用兼容。`/api/health` 新增 `environment` 和 `security_ready`，不返回秘密值。

`backend/.env.example` 已补生产配置示例。
