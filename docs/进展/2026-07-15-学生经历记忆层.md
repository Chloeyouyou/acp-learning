# 2026-07-15 · 学生经历记忆层（借鉴土豆分支三层记忆）

分支 `m-exp-memory`（基于 feat/acp-mature-improvements 3508ced）。
计划见 `docs/计划/2026-07-15-学生经历记忆层计划.md`（含借鉴对照结论与约束）。

## 做了什么

1. **第二层记忆落地**：ACP 原本只有第一层（能力画像）和第三层（会话状态机），
   导师对「这个学生上次怎么踩坑、怎么走出来」一无所知。现在：
   - 新表 `student_experiences`（第 4 张 append-only 表，迁移 d8a4d2cf8080）；
   - `services/experience.py`：内化结算时**确定性**沉淀经历（不经 LLM，摘要由
     pattern 元数据 + error_family 序列 + 提示级 + 卡壳次数 + 内化轴拼成，天然
     不含 expected_fix——落库端泄题硬门控）；
   - 新关卡 `run_turn` 按相关度召回 top2 注入 system（`EXPERIENCE_LAYER_TEMPLATE`
     带注入端硬规则：①②阶段绝不点破成因联系、绝不复述旧题修复代码）。
2. **轻量检索**（移植土豆分支 branch-logic.ts，无向量库）：中文虚词过滤 +
   一/二元字符组覆盖率，按查询规模归一化，`RELEVANCE_FLOOR=0.12` 以下宁可空手。
3. **红线对抗评测** `eval_tutor_redline.py`（真连 LLM 手动跑，仿 eval_question_training）：
   8 条诱导泄题用例（直接索要/冒充老师授权/哀求/收尾套话）——守门前 0/8 尝试泄题、
   守门后 0/8 穿透。
4. **LLM 兜底升级**：run_turn 异常兜底从固定「走神了」改为按阶段的
   `safe_guard_reply`，断网/无 Key 时学生仍收到当前阶段的确定性引导。

## 设计决策

- **摘要确定性生成而非 LLM**：ACP 的结构化事实足够拼出高质量摘要，零成本、可测、
  泄题面为零；LLM 润色留作未来增强。
- **召回排除当前 pattern_id**：变式迁移检验不能被旧经历剧透同题根因。
- **coop 会话不记录不召回**：维持「共脑调试不污染画像」的既有边界。
- **移植时的算法改进**：ASCII 词（IndexError 等错误名）整词作 token、不进字符
  n-gram——原始按字符切会让 IndexError 与 ZeroDivisionError 靠 er/ro/or 碎片
  误判相关（测试先抓出 0.23 > 0.12 门槛的假阳性，随后修复）。
- 历史已完成的会话不回填经历（无回放摘要所需的全部 meta），从上线后自然积累。
