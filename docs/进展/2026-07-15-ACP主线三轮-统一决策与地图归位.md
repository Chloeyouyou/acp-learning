# ACP 主线三轮进展：统一决策与地图归位（2026-07-15）

## 结果

前台现在只给学生一个可解释的下一步，后台再把推荐、复习、未完成会话和全部学习路径归拢到各自清晰的位置：

```text
训练大厅 + 我的成长  <- 同一个下一步决策
学习地图              <- 证据推荐 + 全部学习路径
能力画像              <- 能力结论 + 证据
```

## 决策数据结构

新增 `GET /api/students/{student_id}/next-action`，它是只读、可重算的派生模型，不建表、不写事件：

```json
{
  "action": {
    "kind": "resume",
    "title": "继续想通“边界条件”",
    "detail": "上次停在归因，先把已经开始的思路收完整。",
    "cta": "继续上次",
    "reason_code": "unfinished_first",
    "target": { "session_id": "sess_xxx", "pattern_id": "BP-BOUNDARY-001", "mode": "debug" },
    "evidence": { "type": "active_session", "ref": "sess_xxx", "stage": "④归因" }
  },
  "pending": { "active": 1, "reviews": 2, "recommendations": 3 },
  "decision_order": ["resume", "review", "recommend", "start"]
}
```

## 触发条件

1. 存在未完成非协作会话：续做最近会话。
2. 否则存在到期复习：进入 `review` 模式。
3. 否则存在画像推荐：练当前证据下最值得的一题。
4. 都没有：从一次新练习开始。

`reason_code`、`evidence`、`pending` 和 `decision_order` 让页面不只知道“做什么”，还能说清“为什么先做这个”。
