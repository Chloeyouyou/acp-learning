### D2-3 身份 + 越权门（commit `d2f887e`）
- `app/security.py` HMAC 无密码签名 token（零新依赖，secret 取环境变量或 `.auth_secret` 持久化 + gitignore）；`students` 表；`/api/auth/login`；`current_student` 依赖 + `require_self` 越权门。
- 全部 `/students/{id}/*` + 会话/coop/diagnose 端点接入——**身份只认 token，不再信自报 id**，关审计 #3 IDOR。

### D3-4 Alembic 迁移体系 + updated_at + WAL（commit `4d1ba32`）

### D4-5 会话回合锁 + threadpool（commit `cffc81e`）
- `app/concurrency.py` per-session 内存锁（threading.Lock 分桶）；FastAPI yield-依赖 `turn_lock` 挂所有写会话端点——串行化同会话并发，堵 R2 丢写 + submit TOCTOU（审计 #12）。

## 里程碑 M2 · 过程化（代码链 + 时间线）— 已合并 main（merge `98e31b2`）

### 代码快照（commit `b5f77fd`）
- `CodeSnapshot` 表（append-only，链 execution_event）+ 迁移；`services/process.py` 的 `record_snapshot` + `compute_diff_stats`（`lines_changed` vs 上一版、`touched_mine_line` vs 原始雷行——盲改 vs 定向改信号）。run + submit 双写。

### ④失败回流喂「改动分析」（commit `f4e7598`）
- `process.diff_summary` 把 touched_mine_line 转成给导师的旁白；REPAIR_LAYER 据此分流：盲改→拉回②定位处；定向改错→回③根因对照，仍不给写法。旁白学生看不到、不照念。

### 消息时间线（commit 见 M2 merge）
- `SessionMessage` 表（append-only 真实动作时间线）+ `record_message`；run_turn/run_and_inject/submit/coop.message 埋 dual-write。
- **设计决策**：不彻底迁 `.history`——history 会删旧运行结果（避免污染 LLM 上下文），与回放「保留每一步」天然冲突，故两者各司其职（history=LLM 工作副本、session_messages=回放事实源）。移除 history 列留作后续清理。
