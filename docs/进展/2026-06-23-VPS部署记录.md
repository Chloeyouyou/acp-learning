## 实际步骤（已验证可行）
1. `ssh root@72.11.133.118`（登录时提示 *** System restart required ***，且之前容器已消失，疑似重启后没自动拉起）。
2. `cd /root/acp-learning && git pull` → 从 `f8367db` 快进到 `387547e`（今天所有提交）。
3. `docker build -t acp-learning .` → 成功（pip + npm build 都过，`naming to ...acp-learning:latest`）。
   - ⚠️ 坑：第一次粘贴命令被断行/混入杂字符，报一堆 `Command 'create' not found`。重新完整粘贴整行即可。
4. `docker ps` 空 / `docker ps -a` 空 → 旧容器被彻底删了（网站当时打不开）。
5. `ls -la /root/acp-data/` → `acp.db` 73728 字节、时间 **Jun 19 16:24**（数据在硬盘上，停在 6/19）。
6. 启动（关键，数据持久化）：
   ```bash
   docker run -d --name acp --restart unless-stopped \
     -p 8000:8000 \
     -e DEEPSEEK_API_KEY="<key>" \
     -e DATABASE_URL="sqlite:////data/acp.db" \
     -v /root/acp-data:/data \
     acp-learning
   ```
7. `docker ps` → Up；`curl http://localhost:8000/api/health` → `{"status":"ok","version":"0.1.0"}`。✅

## 持久化原理（已生效）
`-v /root/acp-data:/data` 把宿主机目录挂进容器，`DATABASE_URL=sqlite:////data/acp.db` 让库写到挂载目录。容器删/重建、VPS 重启（`--restart unless-stopped`）都不丢库。
