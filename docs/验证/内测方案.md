# ACP Learning · 3–5 人内测方案（用户验证阶段）

> 目标不是走流程，是**能不能观测到"系统认识你"那一刻**，并判断这个价值是否成立。
> 阶段：暂停开发，纯验证。

---

## ⚠️ 最大的坑（决定成败，先读）
"思维默认值聚合"和"开题前的小检查"有**触发门槛**：同一思维簇里踩过 **≥2 道题**才会出现。
- 若让测试者随便做 2 道题，他**永远看不到**这套东西 → 验证直接失败。
- 所以**测试任务必须走一条"保证撞上同簇"的预设路线**（见第 2 节）。这是命门。

---

## 1. 招募对象（3–5 人）
- **画像**：零基础 / 极少写代码，但对编程**有点好奇又有点怕**的人（学生、朋友）。这是目标用户。
- **要 1–2 个真小白**（完全没碰过代码）——最能检验"帮手 vs 说教"的分寸。
- **避开**：① 资深程序员（会当 debug 工具，错过"学习陪伴"的价值）；② 已听过你愿景的人（会捧场，污染信号）。
- 招 5 个，默认 1–2 个放鸽子。

## 2. 测试任务（预设路线，保证撞上同簇）
每人走一条**固定路线**，不要让他自由选 2 道就结束：

| 顺序 | 题 | 作用 |
|---|---|---|
| 1 | 循环边界差一（BP-BOUNDARY-001） | 热身，学会"运行→观察卡→猜测→导师→修复"这套流 |
| 2 | 空集合未防护（BP-BOUNDARY-002） | 第 1 次踩 `assume_valid` 簇 |
| 3 | 方法返回 None 未检查（BP-NULL-002） | 第 2 次踩同簇 → 思维默认值开始成形 |
| 4 | 字典取值未判空（BP-NULL-003） | 开题瞬间 **Arena 小检查应弹出**（命中同簇） |
| 5 | 让他打开「**成长轨迹**」 | 看 **"你最近常见的思维默认值"** 那一刻的反应 |

**执行要点**
- **两段式**：① 先做题（**全程别提 Timeline、别剧透**）；② 做完再请他自己点开成长轨迹 / 能力画像逛。
- **出声思考**：请他"边做边把心里想的说出来"。
- **你闭嘴**：全程不解释、不推销、不替他操作；卡住先看他怎么挣扎（真信号）。
- **环境**：每人一个**全新身份**（无痕窗口，或先清 localStorage，否则上一人数据会串）；征得同意后录屏。约 30–45 分钟。

## 3. 观察指标（做题时盯着看，记进单人记录表）
- 他**真的看运行结果 / 填观察卡**，还是干等导师？（验证"自己发现"的灵魂）
- **小检查弹出时**：注意到了吗？读了吗？**改变行为了吗**（真去试空输入）？还是无视 / 嫌烦？
- **看到思维默认值那一刻**：有没有**"愣一下 / 诶这真是我"**——核心信号，专门记有没有发生。
- 认知根因标题让他**点头**还是无感？
- 卡壳、困惑、想退出的点在哪。
- 完成几道、内化几道。
- 任何没被提示就冒出来的"哇"。

## 4. 访谈问题（做完问，不要诱导）
1. "用**一句话**形容这个产品像什么？" ← 听"错题本 / 刷题" vs "懂我的教练 / 它记得我"
2. "刚才**哪个瞬间**印象最深？" ← 看他自己会不会提 Timeline / 小检查
3. "看到『你最近常见的思维默认值』那段，第一反应是什么？**说得准吗？是你吗？**"
4. "如果**删掉成长轨迹**这一页，你会觉得可惜吗？为什么？" ← 价值强度
5. "做题时上面那条小提示，你**注意到了吗？有用还是打扰？**"
6. "如果这个系统是**一个人**，它像什么角色？"（老师 / 教练 / 班主任 / 朋友？）← 镜子 vs 审判
7. "愿意**自己继续用**吗？会**推荐给谁**？"
- ❌ 别问"是不是觉得它很懂你？"（诱导，答案没用）。

## 5. 判断"系统认识你"是否成立（可证伪标准）

**✅ 成立（可继续往这条线走）**
- **≥3/5 人**在看到思维默认值时、**没被提示就**出现"愣一下 / 这挺准 / 被说中"；**且**
- 被问"像什么"时，**≥半数**用"懂我 / 认识我 / 记得我 / 像教练"类词，而非"错题本 / 刷题"。

**❌ 不成立（回炉）**
- 普遍当成"又一个错题本 / 刷题工具"；
- 思维默认值"不像自己 / 太泛"；
- 小检查被无视，或觉得像说教。

**🔬 最锋利的一问（测"认识你"是真是幻觉）**
> "你觉得这是在说**你**，还是**任何人**做这几道题都会显示一样的？"

若他意识到"其实是通用的"——说明现在的"认识你"靠**文案写得好**撑着，而非真个性化。这直接告诉你**下一步要不要做 `thinking_pattern` 自动推断 / 个性化**（路线图里那个扩展点）。

## 样本量说明
3–5 人是**定性、找方向**，不是统计显著。看的是**强信号和共性**（多人同一处发亮 / 同一处卡死），不是百分比。
