# 认知先验层（Cognitive Prior Layer）计划 — 2026-07-16

## 是什么

三层记忆的第三层雏形：从多次经历里提炼「这个学生通常怎样理解、求助、行动」的**思维默认值**，
作为导师讲解的**起点参考**（不是标签、不是终点）。经历层回答「过去发生过什么」，
先验层回答「根据连续证据，他通常怎样思考——但本轮如果不同，以本轮为准」。

定位：**可拆卸的共享核心**。第一宿主是 ACP，将来灵犀等项目可整包搬走复用。

## 架构与拆卸纪律（四条，破一条就算失败）

1. **`app/priors/` 包零依赖 ACP 内部**——不 import models/db/tutor/experience。
   输入是通用 `Evidence(text, source_id, at)`，输出是通用 `Prior`。LLM 以 callable 注入。
2. **ACP 侧只有一个薄适配器** `services/prior_adapter.py`——ACP 认识 priors，priors 不认识 ACP。
3. **存储独立命名空间**——`backend/priors_data/{student_id}.json`（env `ACP_PRIORS_DIR` 可覆盖），
   不进 ACP 数据库，迁移=搬目录。**不动事件流四张表，不需要 alembic。**
4. **人类可读可纠正**——JSON 直接打开能看懂；手动删错误先验即生效。

## 三条硬规则（写在包内部，不依赖宿主自觉）

- **3 证据门槛**：推断类先验须有 ≥3 条**不同来源**（source_id 去重）的证据才从候选区
  晋升为 active，才允许注入。样本量 2 的人格判断比没有更糟。
- **临时态隔离**：蒸馏 LLM 必须给每条观察标 durable/transient；transient 进临时区、
  带 48h TTL、过期即弃、**永不**参与先验固化。「今天很累」不许变成「不喜欢复杂解释」。
- **当前 > 先验**：注入措辞由包内 `inject.py` 强制生成——「历史倾向仅作起点参考，
  本轮表现矛盾时一律以本轮为准」；且绝不当面给学生贴标签。

另有两条派生规则：
- **来源类型**：`stated`（学生明说，将来接 UI）/ `inferred`（蒸馏推断）。置信度不写数字，
  证据条数与新旧就是置信度。
- **反例退休**：active 先验累计 2 次矛盾证据 → status=retired（不删除，留档可查）。

## 数据形态（`priors_data/{student_id}.json`）

```json
{
  "student_id": "stu_x",
  "priors":     [{"id","statement","kind","domain":"learning","evidence":[{"source_id","at"}],
                  "contradictions":[...],"status":"active|retired","created_at","updated_at"}],
  "candidates": [同上，未过 3 证据门槛],
  "transient":  [{"statement","expires_at"}]
}
```

## 接线（对 tutor.py 只有两处小改）

- **写入**：结算处 `experience.record_on_completion` 之后 → `prior_adapter.feed_from_experience(exp)`。
  证据文本 = 经历摘要 + 结构化事实摘录（天然不含 expected_fix，继承经历层的泄题硬门控；
  蒸馏 prompt 再加一道：只总结思维/求助/理解倾向，不写任何题目解法）。
- **读取**：`build system` 的经历召回旁 → `system += prior_adapter.injection_for(student_id)`，
  无先验返回空串，行为与现状完全一致。coop 会话两端都隔离（同经历层）。
- **总开关**：env `ACP_PRIORS=off` 时读写都无操作（VPS 保险丝）。
- **失败关闭**：蒸馏 LLM 挂了/输出垃圾 → 静默放弃本次，绝不影响结算主流程。

- [ ] **S3 人工验证**：真跑一局到内化结算，看 priors_data 里长出候选；手动凑 3 局同倾向，

## 明确不做（v1）

- 不接灵犀（等 ACP 里跑顺、有第二消费者时再拆包）。
- 不做学生可视化纠错 UI（JSON 可读即最便宜的实现，UI 等 v2）。
- 不做情境切片检索（先验总量小，全量注入 top3 即可）。
- 蒸馏不后台异步（结算轮多一次 LLM 调用可接受，慢了再挪）。
