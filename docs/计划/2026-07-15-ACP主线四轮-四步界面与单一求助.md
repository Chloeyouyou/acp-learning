# ACP 主线四轮：四步界面与单一求助（2026-07-15）

## 目标

继续落实“前面做减法，后面做加法”：学生在任何时刻只看到当前一步、一个求助入口和一个主行动；系统内部继续保留六阶段状态机、多种讲解策略、完整证据和兼容路由。

```text
学生界面：四步学习语言 + 一个“我卡住了” + 一个完成后主行动
系统内部：六阶段门控 + 讲解换路 + 符号/概念/调用链 + 完整回放
```

## M1 · 四步对外学习语言

- 建立单一展示映射：
  - `①发现` → 运行观察
  - `②定位 + ③归因` → 定位原因
  - `④修复 + ⑤验证` → 修改验证
  - `⑥内化` → 总结迁移
- 界面只显示四步，不修改后端六阶段状态、退出条件或事件语义。
- 当前任务、进度条和界面文案共用同一映射，不再并列两套流程。

验收：任一内部阶段都能稳定落到一个对外步骤，学生页不再显示“发现/定位/归因/修复/验证/内化”六个并列节点。

## M2 · 单一“我卡住了”求助入口

- 把点行讲解、完整逐行讲解、认符号、补概念和向知返换讲法收进同一帮助面板。
- 面板先按当前四步说清“现在只要做什么”，再按需要逐级展开。
- “还是没懂，换一种讲法”通过现有导师消息通道触发确定性讲解换路，不新建平行教学逻辑。
- 点代码行时自动打开同一面板并聚焦该行，不再另弹一张讲解便签。

验收：主工作区只有一个显式求助入口；换讲法消息能被既有 `TeachingStrategy` 识别。

## M3 · 完成后单一主行动

- 有同类变式时，唯一主按钮是“检验能否迁移”。
- 没有变式时，唯一主按钮消费统一 `next-action` 决策。
- 过程回放保留为安静的次级文字入口。

验收：完成态只有一个强调行动，回放不与继续学习抢焦点。

## M4 · 导航与页面职责收拢

- 能力画像从全局“更多”移除，保留从“我的成长”进入和 `/profile` 兼容路由。
- “AI 共脑调试”和“提问训练”统一归名为“专项练习”，只在一个折叠入口中展开。
- 不合并学习地图与训练大厅，不把教师端混入学生导航。

验收：全局主导航仍是开始练习/学习地图/我的成长；额外入口只表达一个“专项练习”概念。

## M5 · Arena 结构拆分与验证

- 抽出四步进度、单一求助面板和完成后行动为小组件或纯派生模块。
- `Arena.vue` 保留会话编排和工作区组装，不改业务事实来源。
- 补纯函数映射测试与 E2E 关键断言，再跑前端构建、后端全量回归和 Playwright。

验收：组件职责清晰，编译和关键学习链路通过。

## 边界与回滚

- 不改数据库 schema、append-only 事件、六阶段迁移和提示级别。
- 不删除 `/profile`、`/coop`、`/question`、`/replay` 路由。
- 不修改教师端、部署配置或用户已有文档。
- 新组件只消费既有状态和 API；任一步都可回退为 `Arena.vue` 内联展示，不影响历史数据。
