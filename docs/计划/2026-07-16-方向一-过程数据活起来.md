> M3 期间做完**(process.derive_turning_points,四类标记+主线归拢+测试),本计划只做剩下两块。

## 范围

- **1.1 导师看得见历史模式**:`process.recent_struggle_signal()` 纯派生,读该生近期
  会话+快照,产出两类跨局信号,拼进导师 system prompt 旁白:
  - 同题重开:之前 ≥2 局没走完 → 「第 N 次打开这道题,都停在某阶段附近」;
  - 试探开局惯性:近 3 局(有可判快照的)里 ≥2 局都是失败后两版以上才碰关键行。
- **1.3 「我的调试足迹」周报**:`timeline.debug_footprint()` 纯派生聚合近 7 天——
  练了几题/几次尝试/几天活跃、内化了什么、最常卡在哪一步(扶一把轮按四步语言聚合)、
  哪道题从试探走到定向、高频思维默认值是否松动。挂进 `/timeline` 响应,
  前端「我的成长」页顶部加一张周报卡。

## 红线(动手前立好)

1. 1.1 是**旁白**:导师绝不照念(不说「你已经第几次」「你总是盲改」),只调引导切入点;
   不改任何阶段门控/提示级别规则;学生本轮表现优先。措辞硬规则写进模板。
2. 全部**纯派生只读**,不写库、不迁 schema、不动事件流四表。
3. 周报是**镜子非审判**:数字只作证据,卡点用四步语言(display_step),松动/进步优先讲。
4. coop 会话两处都排除(设计 09 防污染)。
