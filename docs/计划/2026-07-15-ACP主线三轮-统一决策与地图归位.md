# ACP 主线三轮：统一决策与地图归位（2026-07-15）

## 目标

解决当前仍然存在的两处结构性重复：

1. 训练大厅与“我的成长”分别计算下一步，未来容易出现优先级漂移。
2. 学习地图和能力画像都承担选题职责，用户不知道应该去哪里找推荐与全部题目。

本轮重组后的职责是：

```text
开始练习：系统给一个可解释的下一步
学习地图：用户主动查看推荐、复习标记和全部学习路径
我的成长：解释过程证据与长期变化
能力画像：只解释能力判断及其证据
```

## M1 · 可解释下一步决策层

- 新增纯派生的 `learning_path` 服务，不建表、不写库。
- 固定优先级：未完成会话 > 到期复习 > 个性化推荐 > 新练习。
- 返回行动类型、目标、标题、理由、CTA、待办数量和决策依据。
- 原 `/active-sessions` 复用同一服务生成摘要，消除重复查询实现。
- 新增 `/students/{student_id}/next-action`，严格沿用本人 token 鉴权。

验收：同一学生在训练大厅与“我的成长”看到相同的行动类型、标题与理由；响应能说明为什么优先这一项。

## M2 · 前端统一消费

- `api.js` 增加 next-action 读取。
- 训练大厅主按钮由统一决策驱动，不再只判断有没有未完成会话。
- “我的成长”从四个请求和本地优先级，收敛为成长轨迹 + 单一决策两个请求。
- 续做、复习、推荐和新练习使用同一个前端目标映射函数。

验收：页面不复制决策逻辑；点击统一行动可正确恢复会话或开对应模式的题。

## M3 · 学习地图接管选题

- 学习地图顶部增加“按证据推荐”，下方保留单元/关卡全路径。
- 已解决题的推荐以复习模式进入，其余推荐进入正常调试模式。
- 能力画像移除“推荐与题库”标签及相关加载、分组和样式。
- `/profile?tab=推荐` 保持兼容，但进入画像时回落到能力视图，并提供学习地图入口。

验收：推荐和全部题目只在学习地图集中出现；画像仍保留知识点证据与按知识点练习的窄入口，不再承担题库浏览。

## M4 · 验证

- 后端测试覆盖四级优先级、理由和待办数量。
- E2E 覆盖大厅与成长页共用同一下一步、地图可见推荐、画像无“推荐与题库”标签。
- Python 语法、前端 production build、后端全量回归和 Playwright 关键链路通过。

## 边界与回滚

- 不改四张事件表 schema，不改 append-only 事实，不改六阶段导师状态机。
- 不删除 `/profile`、`/map`、`/arena` 等原路由。
- 下一步 API 是可重算读模型；回滚只需恢复前端旧请求，不影响历史数据。
- 推荐算法本身不变，本轮只调整组织位置和决策入口。
