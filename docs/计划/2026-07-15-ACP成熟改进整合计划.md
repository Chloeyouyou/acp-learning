# ACP 成熟改进整合计划（2026-07-15）

## 目标

在不重写六阶段状态机、不改变四张事件事实表、不削弱导师红线的前提下，把 ACP 已有的过程数据、固定教学策略和动作治理连接成可见、可度量、可供教师使用的完整闭环。

本轮范围只包含已经具备数据基础、边界清楚、验收可量化的改进：

1. 过程回放 2.0：自动标注关键转折点，展示动作目的、风险与证据编号。
2. 导师策略可观测：把每轮教学路线写入 append-only 消息事实，并提供纯派生指标。
3. 教师端加深：学生钻取、最近会话回放入口、班级共性卡点。
4. 生产安全硬门槛：生产环境沙箱 fail closed，教师口令改用认证请求头。
5. Arena 低风险拆分：只抽无业务状态的阶段进度组件，不重写交互主流程。

明确不在本轮混入：SSE 流式输出、BKT/自适应推荐、完整 Vibe Coding 训练场、Arena 整页重写。这些需要独立里程碑和真实数据验证。

## 约束与决策

- `events` / `execution_events` / `capability_scores` / `knowledge_states` schema 不动。
- `execution_events` / `code_snapshots` / `session_messages` 继续 append-only，只插入不修改历史行。
- `session_messages` 增加可空/默认空对象的 `meta` JSON，用于记录教学策略和阶段上下文；配 Alembic 迁移。
- 回放转折点、教学指标、教师共性卡点全部由事实表纯派生，不新增冗余状态表。
- 教师端试点期继续复用 `ACP_ADMIN_TOKEN`，但传输从 URL query 改为 `Authorization: Bearer`；后端暂保留 query 兼容，便于现有 QA 链接过渡。
- `ACP_ENV=production` 时必须显式配置 `ACP_SANDBOX=docker`、Docker 实际可用，并设置 `ACP_ADMIN_TOKEN`、`ACP_AUTH_SECRET`、`DEEPSEEK_API_KEY`；不满足则启动失败。开发环境保持现有体验。
- Arena 本轮只抽 `StageTracker` 展示组件，父组件仍拥有所有状态和动作，避免高风险重构。

## 实施步骤与验收

### M1 · 过程回放 2.0

- 后端为代码步派生 `annotations`，至少覆盖：首次真实失败、首次定向修改、错误族变化、失败后首次通过。
- 回放响应提供顶层 `turning_points` 摘要。
- 代码步补充 `error_family`，保留 `action_context`。
- 前端展示转折标记，以及 purpose / risk / call_id / execution。

验收：构造“失败 → 未碰关键行 → 定向修改 → OK”的过程，回放稳定标出转折点；旧数据无 metadata 时仍可正常展示。

### M2 · 导师策略留痕与评测

- `SessionMessage.meta` 写入导师该轮的教学路线、是否检测困惑、知识断层、当前核心概念、阶段前后、是否启用止损。
- 新增纯派生 `teaching_metrics`：导师轮数、困惑轮数、换路轮数、知识断层轮数、两轮内恢复数/恢复率。
- 回放中的导师消息携带教学元数据，可选择性展示“知返换了一种讲法”。
- 增加固定场景回归测试，验证正常骨架、困惑换路、知识断层、调用链四类策略，并验证元数据落库。

验收：一轮“听不懂”对话后，数据库消息 meta、回放和指标三处一致；不依赖再次调用 LLM。

### M3 · 教师端钻取与共性卡点

- 教师总览增加按 pattern/stage 聚合的共性卡点，保持纯派生。
- 新增教师学生详情端点：基本进度、当前卡点、最近会话摘要、教学指标。
- 新增教师会话回放端点，复用同一个 `build_replay`，只增加管理员鉴权。
- 前端教师表格可点击学生展开详情，并可进入对应回放。

验收：A/B 两班数据过滤正确；共性卡点只统计筛选范围；教师可钻取，错口令/无口令均 403。

### M4 · 生产安全硬门槛

- 教师/管理员端点优先读取 `Authorization: Bearer`，query token 仅兼容旧调用。
- 教师页面 token 改存 `sessionStorage`，请求不再把口令放入 URL。
- 提供独立的生产配置校验函数；lifespan 启动时执行。
- 健康检查返回运行模式和安全就绪状态，不返回任何秘密。

验收：生产配置缺 Docker、实际 Docker 不可用或缺管理员口令时均拒绝启动；development 不受影响；认证头成功、错误头失败。

### M5 · Arena 小步拆分与总回归

- 抽取纯展示 `StageTracker.vue`，通过 props 接受当前 stage，不持有业务状态。
- 前端 production build 通过。
- Alembic upgrade/check 通过。
- 后端全量测试通过；新增功能覆盖测试通过。

## 回滚边界

- 回放、教师指标均为读时派生，可单独撤下前端展示而不影响事实数据。
- `SessionMessage.meta` 是向后兼容新增列，旧行按空对象处理。
- 生产门槛只在 `ACP_ENV=production` 生效，开发环境不会因无 Docker 被锁死。
- Arena 组件拆分不移动任何网络请求、状态机判断或提交逻辑。
