# 知返固定讲解策略计划（2026-07-14）

## 目标

把“哥哥老师”式讲解从单段风格提示升级为每轮可计算、可注入、可测试的教学策略，同时保持六阶段状态机、泄题红线和事件流 schema 不变。

## 最小改造

1. [x] 在 `tutor.py` 增加结构化 `TeachingStrategy`：记录本轮核心目标、讲解路径、是否切换路径、是否疑似存在知识断层、以及代码讲解顺序。
2. [x] 用确定性规则从 `stage / stalled_turns / 当前发言` 计算策略：
   - 默认先给整体骨架，再推进一个核心概念；
   - 明确“听不懂/太抽象”等信号或连续无进展时切换解释路径；
   - 出现基础概念求助时先补一个最小前置知识；
   - 涉及代码执行时按“入口→调用→数据变化→返回/报错位置”讲。
3. [x] 把策略作为独立层叠加到现有阶段剧本与止损层，不改变原状态跃迁和泄题门控。
4. [x] 在 `run_turn` 返回值暴露本轮策略摘要，便于前端/调试观测；不新增数据库字段，不修改四张事件表。
5. [x] 为策略选择、切路、知识断层、调用链约束和 Prompt 注入增加纯函数测试，并运行全量测试。

## 验收标准

- 普通轮次生成“整体骨架 + 单一核心概念”的策略。
- 学生说“听不懂/太抽象”时，本轮 `route_changed=true`，且不复用上一条解释路径。
- 基础概念断层能被标记并要求先补最小前置知识。
- 代码类问题的策略明确要求按调用链解释。
- 原六阶段、提示升级、泄题红线和事件结算测试全部通过。
