# ACP 主线归拢与界面降噪计划（2026-07-15）

## 目标

把产品从“六个并列功能入口”重新组织成一条清楚的学习主线：

```text
开始一次真实调试
→ 知返只陪当前一步
→ 学生亲自运行、定位、修改、解释
→ 完成后回看真实动作与关键转折
→ 长期沉淀为成长轨迹、能力画像与教师洞察
```

原则是“前台做减法，后台做加法”：学生刚进入和正在练习时只看到当下最需要的动作；学习完成后，再把证据、回放、画像和教师视角逐层组织起来。

## 约束

- 不删除已有功能，原路由继续可访问；只调整入口层级、默认展开状态和文案。
- 不修改后端 API、数据库 schema、六阶段状态机、事件流或动作治理。
- 不把技术审计字段直接顶在学生面前；审计信息仍保留在回放的折叠层。
- 保持现有暖纸视觉语言，不做整套视觉重写。
- 所有修改必须通过生产构建、后端回归和 Playwright 关键链路。

## M1 · 入口减法

### 全局导航

一级导航只保留：

1. `开始练习` → `/arena`
2. `学习地图` → `/map`
3. `我的成长` → `/timeline`

`AI 共脑调试`、`提问训练`、`能力画像` 收进“更多”次级菜单。教师入口继续隐藏。

### 身份页

- 主标题改为“从这里继续你的学习”；
- 用“陪你想通，不替你写完”解释产品价值；
- 保留学号、可选姓名和旧记录迁移，不增加新说明。

### 训练大厅

- 主标题从模块名改为用户任务：“今天，自己想通一个问题”；
- 有未完成会话时，主按钮优先“继续上次”；无未完成会话时才“开始一次调试”；
- 新题、未完成列表、自由选题降为次级动作；
- 移除大厅直跳画像/题库的重复入口，统一去学习地图选题。

验收：首屏只有一个明显主按钮；全局一级导航不超过 3 项。

## M2 · 练习过程单焦点

- 全屏练习页移除重复导航，只保留品牌、当前关卡阶段和退出。
- 六阶段导航保留作方向感；“观察—猜测—验证—总结”默认只显示当前需要处理的步骤。
- 过往步骤和未到步骤收在“查看完整思考记录”后面，用户主动展开才显示。
- “逐行讲解、认符号、补概念”继续作为按需工具，不与主任务争夺视觉焦点。
- 完成后提供两条清晰去向：回看“我是怎么想通的”，或继续下一次练习/变式。

验收：首次进入关卡时，右侧除阶段方向外只出现一个核心思考任务；所有原有表单和对话能力仍可用。

## M3 · 后层证据归拢

### 我的成长

- 将成长轨迹定位为主成长入口，标题改为“我的成长”；
- 顶部明确一条证据链：“真实动作 → 关键转折 → 内化经验”；
- 提供进入能力画像的次级入口，解释画像来自这些过程证据；
- 保留复习、思维默认值和逐局时间线，但按“下一步—长期发现—过程记录”排序与命名。

### 过程回放

- 顶部先回答“这次我怎么想通的”；
- 真实运行、亲自提交等动作使用人话摘要；
- `risk_level`、`call_id` 等技术审计信息保留在折叠的“技术凭据”中；
- 教学换路、代码 diff 和转折点继续展示。

### 能力画像与教师端

- 能力画像强调“结论来自可回放证据”，并能回到“我的成长”；
- 教师端按“先看班级共性 → 再看学生 → 最后下钻过程”组织说明，不增加新接口。

验收：学生从“我的成长”能理解证据如何变成画像；教师能看懂从班级信号到单局回放的下钻顺序。

## M4 · 验证

- 更新 Playwright：身份页新文案、一级导航三入口、更多菜单、学生回放证据折叠层。
- 后端全量回归保持通过。
- 前端 production build 通过。
- 浏览器关键链路继续覆盖“身份 → 调试 → 提交 → 学生回放 → 教师钻取”。

## 回滚边界

- 所有改造均在 Vue 展示层和测试层；回滚不会影响历史学习数据。
- 原 `/coop`、`/question`、`/profile`、`/replay/*`、`/teacher` 路由保持兼容。
- 若某个降噪默认影响可发现性，可单独恢复入口或展开状态，不需回滚整套主线。
